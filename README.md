# BatteryLab AI
차세대 이차전지 소재 탐색 및 수명 예측을 위한 AI 기반 웹서비스
PINN과 Bayesian Optimization을 활용한 양극재 물성 예측 및 퇴화 분석 플랫폼

# 프로젝트 개요

피지컬 AI(휴머노이드 로봇, 자율주행차, 드론) 시대가 도래하면서, 고성능 배터리 소재 개발이 핵심 병목으로 부상하고 있습니다. 기존 소재 개발은 연구자의 직관에 의존한 시행착오 방식으로 최적 조성을 찾는 데 수천 회의 실험과 3~5년이 소요됩니다.
BatteryLab AI는 물리 법칙을 이해하는 AI가 실험 파트너가 되어, 최소한의 실험으로 최적의 소재를 신속하게 발굴하고, 이를 활용한 배터리 성능을 예측하는 웹서비스입니다.
